## Reproduce

From `TSMP-Core-main`, use `Validation~/Run-Validation.ps1` with `-UnityEditor`, `-Project` and `-Results`:

- Native: `-Step Play`, `-Step Build`, `-Step Player`.
- SDK: `-Step Configuration`, which compiles with `IsEditorBuild=false`.

Both validation manifests must reference the actual Core and Luma4 worktrees. Do not validate an independently edited package copy or use `-nographics` for GPU loopback.

No live VRChat session, SDK world build or IL2CPP validation was performed for this release.
